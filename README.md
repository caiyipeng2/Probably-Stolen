- 经营：每日 3–5 位顾客、成交、日结、7 天房租、12 天贷款、房租上涨。
- 夜间事件：4 张事件卡，含现金与声望选择。
- 存档：3 个槽位中的槽位 1 已接入，顶栏存档/读档；日结自动存档。
- 新手引导：首次进入说明经营流程；第一天首位顾客固定为拾荒客卖家，便于上手。
