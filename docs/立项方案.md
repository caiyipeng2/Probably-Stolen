# 《深空当铺：可能是偷的》手机版移植立项方案（全量 1:1 版）

- 日期：2026-11-11
- 状态：M14 机器随机故障与维修事件已交付（2026-11-12，私有版）；剩余内容见 `docs/内容对齐清单.md`
- 已确认：最终范围全量 1:1；素材私有自用 + 公开版替换；主界面效果图方向确认
- 目标平台：Android 横屏优先，iOS 后置
- 引擎：Godot 4.7.2 stable（本机已装，含导出模板）
- 真机：Samsung SM-S9280，Android 16，2340×1080

## 1. 项目目标

把《深空当铺：可能是偷的》完整移植为手机版：核心循环、像素画风、黑色幽默、赛博朋克氛围与原版基本一致，最终覆盖原版的物品、顾客、派系、机器、剧情、战斗与结局。

范围原则：**全量 1:1 是最终目标，不永久删减系统**。开发按模块累计推进，先构建可玩骨架，再逐模块补齐全部内容；过程版本不作为最终范围承诺。

## 2. 调研与拆解结论

- 开发商/发行：Questing Goose Studio / tinyBuild；2026-10-28 发售；Steam App 4348910。
- 本地版本：Unity 2021.3.45f2，Mono 构建，约 1.09 GB。
- 代码：Assembly-CSharp 反编译 2788 个类型，0 失败；存在 Harmony、Mods 目录、Quantum Console。
- 内容量：约 330 件可交易物品、49 项网络升级、13 种开局专精、8 个派系、2544 条对话、804 条 UI 文本、220 个机器相关类、约 2415 个 Sprite。
- 核心循环：开店 → 顾客上门 → 验货/鉴定 → 估价 → 议价/威胁/勒索 → 成交或藏匿 → 晚间结算 → 交租/还贷 → 升级/声望 → 下一天 → 买下店铺。
- 画风：16px 基础像素素材 4× 放大；青灰蓝阴影、琥珀高光、锈红点缀；深色机械终端 + 浅色纸质档案两套 UI 语言。
- 手机版机会：2340×1080 横屏的额外宽度放侧边触控栏；底部抽屉替代常驻背包；长按替代悬停；自动旋转/自动整理降低拖放精度要求。

## 6. Godot 技术方案

- Godot 4.7.2 stable，GDScript（静态类型），Compatibility 渲染器，2D。
- 逻辑分辨率 1920×1080，16:9 内容居中，超宽屏两侧放触控栏；像素素材 1× 存储、整数倍放大、Nearest 过滤。
- 中文字体：Fusion Pixel 12px（OFL）或同风格开源像素字体；字号取 2×/3×/4×。
- 场景拆分：Main、DayCycle、CustomerQueue、InventoryGrid、Inspection、Bargain、Machine、Combat、Save、Audio、UI。
- 数据驱动：物品/顾客/事件/升级/配方用 JSON；本地化 CSV；内容与代码分离。
- 输入：点选、拖放、长按、双击、震动反馈；提供自动放置/自动旋转/自动整理。
- 存档：JSON + 版本号 + 原子写入；3 槽 + 自动存档；异常存档回退。
- Android：APK/AAB；minSdk 24、targetSdk 35；真机 SM-S9280 验收。
- MCP：Coding-Solo/godot-mcp 负责启动编辑器/运行/读取调试输出；adb/scrcpy 负责真机截图与输入。

- 主界面效果图：`_research/mockups/phone/phone_main.png`（2340×1080），作为 UI/画风方向确认稿。

## 9. 风险与已确认决策

- 范围风险：全量 1:1 是长期工程；按 M1–M6 累计推进，始终保留可运行版本。
- 版权风险：拆包素材仅限个人私有移植；公开版必须原创/生成替换。
- 技术风险：Godot Android 导出链、字体体积、超宽屏适配、触屏拖放精度、战斗与机器系统复杂度。
- 内容风险：物品数据在 C# 工厂方法中生成，需要半自动提取 + 人工校对；按 M2 全量对齐。
- 已确认：全量 1:1；私有自用 + 公开版替换；主界面方向确认。
