1. **买店线价格 5000 → 2000₵**：第 10 天现金中位数 1708、75 分位 1822，2000 是“经营得不错才够得到”的目标；原 5000 在当前 10 天循环中不可达。
2. **通缉目标 3 → 9 名**：补齐原版通缉角色名册（屠夫、詹姆斯·贝利、亚瑟·拉弗勒、奥丁、卢、李北文、胡安等），复用现有战斗规则。
3. **新增 Boss“卢”**：80 HP、10–14 伤害、1500₵ 赏金，作为终局挑战。
4. **剧情任务经济**：Georgio 入门线（第 1 天）给 3 份废金属补偿，保证新手买下“遗物”后不亏空；Serpico 线用剧情顾客预算 100–120₵，不挤压主线资金。

## 4. 边界

- 模拟使用完美信息（直接读市价），真人玩家需要鉴定与判断，实际收益会更低。
- 未模拟机器生产、网络升级、专精、电话委托、夜间事件的长期收益；这些系统会进一步提高上限。
- 战斗为简化回合制，未模拟武器/义体/掩体；Boss 40% 胜率基于当前规则。
- 后续如果扩展天数到 30–40 天，房租曲线与买店价格需要重新模拟。
