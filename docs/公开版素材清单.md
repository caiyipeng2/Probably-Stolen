# 公开版素材清单

- 目标：公开仓库/公开构建不包含拆包素材；私有素材缺失时自动回退到 `assets_public/`。
- 生成脚本：`_research/tools/gen_public_assets.py`（程序化生成，不依赖原版素材）
- 预览：`godot --path . --capture --publicassets`（桌面截图 `_research/mockups/phone/m1_ui.png`）

| 类别 | 文件 | 说明 |

| 音频 | `assets_public/audio/*.ogg` | 原创 24s 主音乐、20s 环境音、12 个音效 |

## 回退顺序

1. `assets_private/`（私有构建，拆包素材）
2. `assets/`（本机兼容旧路径）
3. `assets_public/`（公开替换素材，逐物品图标优先于分类图标）
4. 物品图标回退到 `assets_public/icons/generic.png`
5. 音频回退：私有 `assets_private/audio` → 公开 `assets_public/audio`

`--publicassets` 参数会跳过第 1/2 步，直接使用公开素材，用于公开版验收。
