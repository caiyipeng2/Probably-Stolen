# 全量 1:1 还原计划（1–9 项）

- 日期：2026-11-12
- 对照源：本机 Steam 版《深空当铺：可能是偷的》+ `_research/decompiled` 反编译代码 + 原版本地化表
- 原则：配置/规则先提取，再实现，再用对照报告验收；每一项目标是“原版有哪些、当前有哪些、差在哪、下一步补什么”

## 验收方式

每个条目完成后在 `docs/parity/` 下生成对照报告：

- `0X_*.md`：原版数据来源（类/方法/本地化 key）、数量统计、当前实现、逐项差异、未实现清单
- 每个系统同步补 headless 测试（必要时真机验证）
- 对照报告必须能回答：配置表字段、数量、触发条件、效果、UI 行为是否一致

## 实施顺序

1. 对照基线与数据提取器（第 1、2 条优先）
2. 第 1 条：剧情图数据 → 通用图运行时 → 原版日程 → 对照报告
3. 第 2 条：机器配置 → 配方/套件 → 对照报告
4. 第 3–7 条按依赖顺序实现（验货 → 背包 → 交易 → 战斗 → 犯罪）
5. 第 8 条本地化（机械替换，最后做避免反复改 UI）
6. 第 9 条资源覆盖（私有构建优先，公开替换保持现有回退）

## 说明

- 原版“220 个机器相关类”包含大量 UI/辅助/嵌套类；实际生产机器以反编译类中的机器实现为准，对照报告会区分“生产机器/辅助类/装饰类”。
- 2544 条对话包含大量随机顾客/以物易物/阶层顾客台词，不一定都是分支图；第 1 条会区分“剧情图节点”和“顾客台词池”，两者都纳入覆盖统计。
- 公开构建继续使用 `assets_public/` 原创素材；私有构建允许使用本机拆包素材，但不进入公开仓库。
- Steam 成就/创意工坊/Mod 不在 1–9 范围内。
